# 排氨與泌尿：概念圖練習 2.0.3

此資料夾是**完整 GitHub Pages 上傳包**，並非差異補丁。以排氨 2.0.2 為基礎改良拖曳與回饋，**不覆蓋 1.0**。

## 操作方式

1. 從「器官卡」拖出器官，放在畫布任意位置。可以自由移動；若想收回，**直接拖回器官卡區**，相關連線會同步刪除。不需要「收回器官」按鈕。
2. 依序點兩張器官卡，建立帶方向的箭頭。再次點選原本已連接的兩張器官，可以取消連線；要改方向可先取消再重新選擇起點與終點。
3. 從「物質卡」拖至箭頭中間的框內。靠近時會出現磁吸提示；放開手指便吸入。物質卡可重複使用。
4. **按住線框中已放好的物質卡並拖出**：拖到另一條線可重新安置，拖到空白處就會從原線移除；輕點已放入的物質也可取下。拖曳被中斷時會恢復原物質。
5. **即時提示：關（預設）**：可放入任意物質，完成後按「檢查架構」一起判定。**即時提示：開**：物質不適合該連線時會短暫彈開，已附著的物質拖去錯誤連線會回到原位；不直接提示正確答案。這是幫助方式的開關，不是學生程度標籤。
6. 「貼齊格線」預設關閉。第一次打開會就近整理已有器官，往後每次移動完成才貼齊；不會替學生排出標準答案。
7. 全部七條必要、**不重複**的路徑都正確且沒有多餘連線才會顯示完成。原版肺與腦兩張代表卡已整合為「各處器官」。

## 上傳到 GitHub Pages

1. 建立新儲存庫或使用原本測試用的 `ipad-test-anomi-v2`。
2. ZIP 解壓後，將**整個資料夾內容**（包含 `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、`unit.json`、`icons/`）上傳到儲存庫**根目錄**。不要把 ZIP 當成單一檔案上傳。
3. 在 GitHub **Settings → Pages** 選擇 **Deploy from a branch / main / (root)**。
4. 用 HTTPS Pages 網址測試功能後，iPad 使用 Safari「分享 → 加入主畫面」進行單元安裝。
5. 更新已安裝的舊版時，連網關閉舊網頁和 App、再重新開啟；Service Worker 會逐步換到新快取。不要刪除 1.0 儲存庫。

## 離線與整合入口

本單元有獨立 manifest、圖示、Service Worker 與 `unit.json`。首次連網完成必要資源快取後，可嘗試離線開啟；**必須在真實 iPad／Safari 飛航模式下關閉重開驗證**。這個單元能獨立安裝，但不表示既有大入口網已包含它的離線檔案。未來整合時需把單元檔案部署到入口網受控的路徑，更新入口網資源清單與快取策略。

## 尚待實機驗收

- 物質卡的磁吸、從線框拔出、移動到新線框、錯誤彈回的操作手感。
- 電腦／平板／手機版面、安裝 icon，以及斷網重新開啟。
