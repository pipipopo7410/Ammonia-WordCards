# 排氨與泌尿 2.0.2｜GitHub Pages 測試版

這是基於老師提供的 **排氨 1.0 `index.html`** 改良的獨立 2.0 測試版。**不會變更既有 1.0 網站**。

## GitHub 上傳（不用使用 Work）

1. 在 GitHub 建立新的 Public repository，建議 `ipad-test-anomi-v2`，**不要覆蓋 `ipad-test-anomi`**。
2. 解壓下載包，進入資料夾，選取裡面所有檔案和 `icons` 資料夾，拖入新 repo 的 **Add file → Upload files**，並 Commit。
3. 在 **Settings → Pages** 設定 **Deploy from a branch → main → /(root)**。
4. 預期網址為 `https://pipipopo7410.github.io/ipad-test-anomi-v2/`，以 GitHub 頁面顯示的正式網址為準。
5. 打開網址，確認拖曳、連線、貼物質、檢查、重設、貼齊格線等操作。

## iPad / iPhone / Android 安裝

- iPad / iPhone：**Safari** 打開 GitHub Pages 的 HTTPS 網址 → 分享 → **加入主畫面**。首次開啟後等待完成快取；再次開啟可在飛航模式驗證。
- Android：Chrome 開啟網址，選單選 **安裝應用程式** 或 **加入主畫面**。
- Apple 與 Android 的實際安裝入口因系統版本不同，網站中的「安裝說明」可隨時開啟。
- `manifest.webmanifest`、`sw.js`、`icons/` 與 HTML/CSS/JS 都使用相對路徑，部署到 GitHub Pages 專案路徑不需要改路徑。
- 請注意：單純雙擊本機 HTML（file://）可以看部分頁面，但無法驗證 Service Worker 與離線 PWA；必須在 HTTPS 站點上驗證。

## 2.0 主要功能與原版差異

- 保留 1.0 的器官、物質、連線方向與尿素排出之教學架構。
- 原版「肺」「腦」兩張代表性器官字卡，改成 **一張「各處器官」字卡**，外圍附腦、眼、唇、骨、臀、肌、肺、心八個裝飾小圓；它們不代表各自的連線端點。
- 原本 9 條必要連線中，兩組肺／腦相關的重複概念合併後，**改成 7 條不同的必要關係**。現在必須七條全部正確才能完成，不可缺少汗液路徑。
- 器官字卡：拖曳到畫布；或點卡再點畫布放置。點畫布上的器官卡 A 再點 B，建立 A → B 方向箭頭；重複選同一對可取消該線。
- 物質卡：拖到線上中間的「＋物質」框；或先點物質卡、再點框。已有物質的框可點一下取下，更換更方便。
- 點畫布上的器官卡後按「收回器官」，可歸還卡池且同步清除相關連線。
- 「貼齊格線」預設關，按開即整理一次已放的卡片，後續移動才自動貼齊；不會幫學生解出正確概念圖。
- 重設完整清空畫布上的所有器官與連線，修正 1.0 殘留錯誤。
- 移除假分頁與 Tailwind CDN，使用本機 CSS / JavaScript / PNG，核心不依賴網路服務。
- 提供響應式排版、專屬安裝 Icon、Service Worker 離線預載。

## 必要關係（七條）

1. 小腸 → 各處器官：胺基酸
2. 各處器官 → 肝：氨
3. 肝 → 腎：尿素
4. 肝 → 汗腺：尿素
5. 腎 → 膀胱：尿液
6. 膀胱 → 體外：尿液
7. 汗腺 → 體外：汗液

細胞代謝與血液運輸在此活動中做了國中程度簡化；器官之間的箭頭是物質運輸示意，不代表器官之間有直接導管。

## 正式驗收清單

- 任取一張器官，拖出、收回、重設，再操作 20 次：不可留下舊卡或重複 DOM ID。
- 少任何一條必要路徑，尤其「汗腺 → 體外：汗液」，都不可顯示完成。
- 錯的物質或倒向箭頭要顯示錯誤，正確完成 7 條才可過關。
- 開啟貼齊格線不會改變連線或將卡片排成預設答案。
- 1024×768 iPad 橫向、直向與手機小視窗都要能操作；觸控與畫面載入不能只依賴電腦模擬。
- iPad Safari：安裝主畫面後，首次完整快取；飛航模式關閉 Safari 再重開，核心活動仍可操作。
- 校園 30 台 iPad 逐批測試快取與更新；不要把單機網速外推到所有裝置。

## 整合到「剛剛數位小教室」的準備

這份包可以**單獨安裝**。未來入口網的「整包安裝」是**另一個 PWA**，不是替九個不同網址逐一安裝九個 App。

當入口網要成為全單元離線套件，請把各獨立單元整份複製到入口 repo 內，例如 `Bio-Class/units/anomi/`，並同時：

1. 讓入口首頁連到 `/Bio-Class/units/anomi/index.html`（建議使用相對連結）。
2. 讓入口的 Service Worker *逐份預載各單元所需檔案*，以 `unit.json` 提供的 `offlineAssets` 為基礎，另含實際執行時動態引用的所有必要資源。
3. 入口 SW 的 `scope` 必須涵蓋 `/Bio-Class/units/`，才能在離線時控制這些頁面。
4. 採 **完整下載成功才標「離線就緒」**，並使用版本化快取，避免舊版題庫與新版 JS 混在一起。
5. 單元保留相對路徑 manifest 和自己的 Service Worker，若要在入口裡**也提供獨立安裝**，可從單元目錄自行開啟並加入主畫面。父子層 Service Worker 的更新與離線範圍需要在實際部署後交叉測試。

**重要：** 目前入口網仍以外部 GitHub Pages 網址連到九站，因此不能直接把其他獨立路徑的活動視為已被入口 SW 離線控制。這份包完成的是獨立安裝與「整包整合所需的單元規格」，尚未修改入口 repo，未聲稱所有九個活動都可整包離線使用。

## 2.0.2 操作修正

- 側欄拖曳器官字卡時，會出現一路跟著手指的預覽卡；必須在畫布上放開才會放置，畫布外放開則保留原卡池。
- 請在部署後以 iPad Safari 重新開啟並測試跨區拖曳；由於 Service Worker 快取版本更新，舊已開頁面可能要關閉重開或重新整理才能載入新版。

## 2.0.2 版面與字體優化

- iPad 橫向側欄從 246px 縮到 220px；釋放畫布空間。
- 畫布器官卡由 106×51px 改為 90×43px，字級由 14px 增為 16px，確保器官字卡比物質標籤更有主體感。
- 路徑上的物質標籤由 69×32px 改為 56×28px；卡池的物質卡也改窄。
- 「各處器官」群組由 180×128px 改為 156×112px；外圈小圓由 30px 改為 25px，中央文字更清楚。
- 同步更新拖曳預覽、連線終點、物質位置避讓及貼齊格線的尺寸計算。
- 不更動七條正確路徑、答案判定、操作流程或 PWA 安裝方式。

**注意：** 字卡外觀變小不應使點擊變得困難，iPad 實機仍需確認手指命中率。
